# GBC Server GitHub 版

GitHub 版移除玩家 `index.html` 官网首页、首页专用样式和介绍图片，保留玩家登录、服务器状态页、管理员系统及其必需资源。访问根路径会进入 `/login.html`；`/index.html` 和首页专用资源返回 404，管理员入口默认是 `/admin/`，首次启动后可在数据库中更改。

管理员运行配置可修改系统名称、玩家登录页标题、状态页标题和页脚，也可增删状态目标和第三方状态 API。文案保存后重新加载页面即可生效；状态目标与 API 配置仍需重新加载服务。

每个平台压缩包只含一个完整系统程序和本说明。它不含 `index.html` 主页、插件 JAR、插件配置模板、数据库、头像、商品图片、凭据或源码。需要游戏插件时，单独从项目源码构建并安装对应 JAR。

启动程序后访问管理员入口，首次登录前先设置管理员账户、密码和 TOTP。管理页面可配置监听、邮件与状态服务，签发和撤销插件令牌，重新加载或停止运行中的服务，并管理当前用户的开机自启。

```text
gbcserver start
gbcserver plugin-token
```

`plugin-token` 会显示交互菜单。它读取当前运行数据目录中的 `gbcserver.db`。自定义目录时使用 `plugin-token --data-dir <目录>`。

此分支只构建 GitHub 版，可运行 `source/build.ps1` 构建九个平台，再运行 `source/package.ps1` 生成部署 ZIP。部署包不包含数据库或其他运行数据。
